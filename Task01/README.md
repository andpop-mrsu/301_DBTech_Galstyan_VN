# Task01

## Структура файлов

### Файлы с данными

- `movies.csv` - информация о фильмах: идентификатор фильма, название и жанры.
- `ratings.csv` - оценки пользователей: идентификатор пользователя, идентификатор фильма, тег и временная метка.
- `tags.csv` - теги пользователей для фильмов: идентификатор пользователя, идентификатор фильма, тег и временная метка.
- `genres.txt` - список жанров фильмов, каждый жанр записан с новой строки.
- `occupation.txt` - список профессий пользователей, каждая профессия записана с новой строки
- `users.txt` - информация о пользователях: идентификатор, имя, электронная почта, пол, дата и профессия.

### Программа и результаты

- `task1.go` - программа на Go для обработки файла `ratings.csv`.
- `ratings_count.txt` - результат выполнения программы: минимальный и максимальный идентификаторы пользователей и количество записей с каждым из них.
- `sqlite.txt` - информация о версии SQLite и режимах вывода данных.
